### SA01: Generic Case Management Architecture, Universal 5-Stage Lifecycle & 3-Step Due Ledger API

- **Date**: 2026-08-18
- **Impact**: Backend Architecture, Generic REST API, Extensible Case Schema, Payment & Due Ledger, Central Customer Linking
- **Description**:
  - Designed and implemented a .NET-style **Generic REST API & Case Management Engine** eliminating hardcoded country route vectors.
  - Built `caseFile.model.js` supporting extensible `caseType` (Greece, North Macedonia, Indian BSF, Poland, etc.), 5 universal lifecycle stages (`ENTRY` → `PROCESSING` → `APPROVED_OFFER_LETTER` → `SUBMITTED_EMBASSY_BSF` → `COMPLETED_DELIVERED`), 4-item document checklist with follow-up call flags, 3-milestone payment tracking, auto/manual due calculations, and `extraData` dynamic storage.
  - Built `caseFile.controller.js` with `buildGenericCaseQuery` supporting comma-separated multi-value `$in` filtering (`?caseType=greece,n-macedonia`, `?status=ENTRY,PROCESSING`), regex keyword search across 5 fields, due range filters (`hasDue`, `dueMin`, `dueMax`), date range queries, sorting, pagination, fast `/lookup` endpoint, company-wide `/summary` aggregation, and `/bulk` migration for 250+ legacy files.
  - Created `CaseFileRoute.js` mounted at `/api/v1/cases` in `routesIndex.js`.
  - Updated `customer.model.js` with `cases` relation array for two-way referencing.
  - Created comprehensive documentation in `Docs/SA/001_Overview.md`.
