# Backend Change Logs (MB01 - MB100)

This document tracks changes made to the `backend` project for Monsur Ali Travels ERP. Entries are sorted with the latest at the top.

### MB02: Decouple Payment Model and Controller for Standalone ERP Payments

- **Date**: 2026-08-14
- **Impact**: Backend Financial Models & Payments Controller
- **Description**: Decoupled the payment system from mandatory e-commerce order restrictions. Made `orderId` optional and introduced references for `billingId`, `memberId`, and `paymentType` (such as `payout`, `salary`, `supplier_bill`, `advance`, `billing`, and `general`), along with `notes` and `transactionRef`.
- **Changes**:
  - Updated [`payment.model.js`](file:///f:/Monsur%20Ali%20Travels/backend/src/models/payment.model.js) to make `orderId` non-mandatory (`required: false`) and added `billingId`, `memberId`, `paymentType`, `transactionRef`, and `notes`.
  - Updated [`PaymentsController.js`](file:///f:/Monsur%20Ali%20Travels/backend/src/controllers/PaymentsController.js) to support standalone payment creation and advanced ERP filtering without requiring an e-commerce order ID.
