### AD06: Strict 100vh Viewport Constraint & Fixed Navbar Height in Admin Layout

- **Date**: 2026-08-21
- **Impact**: Layout Architecture, Viewport Constraints, Internal Scrolling
- **Description**:
  - Enforced strict `100vh` outer viewport height (`h-screen w-screen overflow-hidden`) preventing full-page document scrolling.
  - Fixed topbar navbar to explicit `64px` (`h-16 shrink-0`), matching sidebar header.
  - Set dynamic content container to `h-[calc(100vh-4rem)] max-h-[calc(100vh-4rem)] overflow-y-auto`, enabling smooth internal scrolling while keeping navbar and sidebar anchored.
  - Verified error handling across all admin modules to ensure errors render exclusively via toast notifications.
- **Files Modified**:
  - `dashboard/admin/src/components/layout/AdminLayout.jsx`
